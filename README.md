**Análisis de ventas online de una tienda ecuatoriana**

**Actividades principales:**
- Limpieza y transformación de datos mediante Power Query.
- Estandarización de fechas, precios y categorías.
- Modelado de datos mediante Power Pivot.
- Análisis mediante tablas dinámicas y segmentadores.
- Desarrollo de un dashboard interactivo para analizar ventas, ingresos y estados de pedidos.

**Herramientas:** Excel · Power Query · Power Pivot · Pivot Tables

**Hallazgo destacado:** Identificación de diferencias entre volumen de ventas e ingresos por ciudad, además de posibles problemas de gestión logística.

### 🗄️ 03. Market360 E-Commerce Analytics | SQL

**Análisis de ventas, clientes y desempeño de productos**

Desarrollé un proyecto de Business Analytics utilizando el dataset público de Olist y SQL Server para identificar patrones comerciales y oportunidades de mejora.

**Actividades principales:**
- Exploración y análisis de bases de datos relacionales.
- Construcción de consultas SQL con JOINs, agregaciones y subconsultas.
- Diseño de un modelo dimensional tipo esquema estrella.
- Desarrollo de consultas mediante CTEs.
- Creación de vistas SQL reutilizables.
- Segmentación de clientes, productos y categorías.
- Elaboración de recomendaciones estratégicas basadas en los resultados.

**Herramientas:** SQL Server · T-SQL · JOINs · CTEs · Star Schema

**Hallazgos destacados:**
- El 28,7 % de los clientes concentra el 66,6 % del gasto analizado.
- El 72,3 % de los productos presenta ventas inferiores al promedio.
- Se identificaron segmentos de clientes históricamente inactivos.

🔗 [Ver proyecto en GitHub](https://github.com/TU-USUARIO/sql-market360-ecommerce-analytics)

### 🐍 04. Comercial Andina | Python Sales Analytics

**Análisis predictivo de ventas y evaluación de promociones**

Desarrollé un proyecto de análisis estadístico y Machine Learning utilizando datos históricos de una empresa de retail simulada.

**Actividades principales:**
- Preparación y exploración de aproximadamente 2 millones de transacciones.
- Limpieza y transformación de datos con Python.
- Análisis exploratorio y visualización de tendencias.
- Entrenamiento de un modelo de regresión lineal con Scikit-Learn.
- Evaluación del modelo mediante R², MAE y RMSE.
- Aplicación de pruebas de hipótesis para analizar promociones.
- Interpretación de resultados y recomendaciones comerciales.

**Herramientas:** Python · Pandas · Scikit-Learn · SciPy · Plotly

**Hallazgo destacado:** El modelo lineal presentó un R² cercano a cero, evidenciando limitaciones predictivas con las variables utilizadas. La prueba de hipótesis no encontró evidencia estadística suficiente de diferencias en el importe promedio por transacción asociadas a las promociones.

🔗 [Ver proyecto en GitHub](https://github.com/TU-USUARIO/python-comercial-andina-sales-analysis)
